# Python Programming Practical Repository - Unit 1

Contains 30 standalone Python programs for Unit 1: Foundations of Python and Control Structures.

## Run a program
1. Open this folder in VS Code.
2. Open a `.py` file.
3. Run it using the Run Python File button or terminal: `python filename.py`.

## Important
Several questions do not specify tax rates, salary percentages, bill slabs, loan criteria, admission criteria, pass marks, or ATM rules. For those programs, clearly marked **example assumptions** are used. Adjust them to match the values given by your instructor.

Program filenames start with the assignment question number.
